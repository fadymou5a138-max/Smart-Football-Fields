# Smart Football Fields — Frontend



## الصفحات
- `index.html`: الصفحة الرئيسية والبحث عن الملاعب.
- `field-details.html`: تفاصيل الملعب واختيار اليوم والموعد.
- `booking-review.html`: مراجعة البيانات واختيار مدة الحجز وطريقة الدفع التجريبية.
- `booking-success.html`: تأكيد الحجز وطباعة التذكرة.
- `my-bookings.html`: عرض الحجوزات وتصفيتها وإلغاؤها.
- `admin-dashboard.html`: ملخص حجوزات وإيرادات اليوم.
- `admin-bookings.html`: البحث في الحجوزات وتصفيتها وإلغاؤها.
- `fields-pricing.html`: إضافة الملاعب وتعديل الأسعار.
- `irrigation.html`: إعدادات تحكم تجريبية للري والمضخة.
- `design-system.html` و`user-flows.html`: صفحات التوثيق.

## ما تم استكماله في المرحلة الأولى
- تصحيح مسارات CSS وحذف الاستدعاء الخاطئ `style.css` من جذر المشروع.
- توحيد ملف JavaScript المشترك في `js/script.js`.
- تحسين التنقل وتحديد الصفحة النشطة وإغلاق القائمة الجانبية على الهاتف.
- تفعيل البحث والتصفية حسب المنطقة ونوع الملعب.
- تمرير الملعب والتاريخ المختارَين إلى شاشة التفاصيل ومراجعة الحجز.
- إظهار المواعيد المحجوزة وتعطيلها، والتحقق من تعارض المدة قبل تأكيد الحجز.
- التحقق من الاسم ورقم الهاتف والمدة والتاريخ قبل إنشاء الحجز.
- حفظ الحجوزات والملاعب وإعدادات الري وحالة المضخة في LocalStorage.
- تفعيل تصفية الحجوزات والإلغاء وتحديث إحصائيات لوحة الإدارة.
- إظهار بيانات الحجز الصحيح في التذكرة وإضافة زر طباعة.
- تحسين حالات التركيز ولوحة المفاتيح وحالات المواعيد غير المتاحة.

## حدود هذه النسخة
هذه مرحلة Frontend تجريبية فقط. البيانات محفوظة في المتصفح عبر `LocalStorage`، ولذلك لا تتزامن بين الأجهزة أو المستخدمين. حالة المضخة والري محاكاة واجهة وليست اتصالًا فعليًا بحساسات أو ESP32. خيارات الدفع لا تنفذ معاملة مالية فعلية. لا يوجد Backend أو قاعدة بيانات أو تسجيل دخول وصلاحيات في هذه المرحلة.

## الاختبارات المنفذة
- فحص صياغة JavaScript باستخدام `node --check`.
- فحص وجود ملفات CSS وJavaScript المشار إليها في صفحات HTML.
- فحص الروابط الداخلية لصفحات المشروع وعدم وجود معرفات HTML مكررة.
- فحص سلامة أرشيف ZIP بعد إنشائه.

لم يتم إجراء اختبار بصري آلي داخل متصفح حقيقي في بيئة البناء؛ يُنصح بتجربة مسار الحجز على Live Server قبل العرض.


## ملفات PWA والهوية البصرية المضافة
- `manifest.json`: إعدادات تثبيت التطبيق على الهاتف/الكمبيوتر.
- `sw.js` و`js/pwa.js`: تسجيل Service Worker وتخزين ملفات الواجهة الأساسية للعمل دون اتصال بعد أول تحميل.
- `assets/icons/icon-192.png` و`icon-512.png`: أيقونات PWA.
- `assets/icons/logo-1024.png`: الشعار الشفاف عالي الدقة.
- `assets/images/og-image-1200x630.jpg`: صورة المشاركة Open Graph.
- `assets/images/website-cover-1080x1920.jpg`: غلاف الموقع الطولي.
- `assets/images/facebook-post-1200x630.jpg`: منشور فيسبوك.
- `assets/images/instagram-post-1080x1080.jpg`: منشور إنستجرام مربع.
- `assets/images/instagram-story-1080x1920.jpg`: ستوري إنستجرام.

**مهم:** تثبيت PWA وService Worker يحتاج تشغيل الموقع عبر HTTPS (مثل GitHub Pages) أو `localhost`، ولن يعمل بشكل كامل عند فتح ملفات HTML مباشرةً من الجهاز.
